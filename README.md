## Usage

Each skill directory contains a `SKILL.md` defining the agent instructions and any supporting scripts or references.

To use these skills globally with Antigravity or Gemini CLI, symlink or copy individual skill folders to `~/.gemini/config/skills/`.

## Personal skills sync

This repository also includes the personal skills installed in Codex user folders. It currently contains 59 skills (including the nested `workctl-operator` skill).

For Codex, install skill folders in `~/.agents/skills/`. Existing installations in `~/.codex/skills/` can remain there; avoid creating duplicate copies. For Gemini, install in `~/.gemini/config/skills/`. Built-in system and plugin skills are excluded.

### Additional synced skills

- `motion`: web animation guidance and Motion tools. Some features require the Motion MCP server or Motion+.
- `marketing-graphics` and `content-scripts`: Noble Casca-specific workflows. Run against the Noble Casca project context; they reference its `project-docs/brand-source-of-truth.md` and `project-docs/session-log.md`. Project documents are not bundled here.
- `data-warehouse-source-setup`: PostHog source setup, including its bundled references. Requires the relevant PostHog tools or browser setup.

## README maintenance rule

Whenever a skill is added, imported, installed into this collection, or synced into this repository, update this README in the same change before committing or pushing:

1. Add the skill's exact name and a concise, accurate focus to the **Included Skills** table, based on its `SKILL.md`.
2. Link its name to its `SKILL.md`, including the correct path for nested skills.
3. Keep the table alphabetized, with exactly one row per skill, and update the total skill count.
4. Document project context, supporting files, or tool dependencies needed to use the skill.
5. When a skill is renamed, removed, or changes focus, update its row and any affected usage notes.
6. Verify that every `skills/**/SKILL.md` has a matching table row and every table link exists before reporting the sync complete.

A skill addition or sync is incomplete until its name and focus appear in this README.
