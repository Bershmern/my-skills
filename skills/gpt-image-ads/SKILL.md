# GPT Image Ads Generator

## Overview
Use this skill when the user needs visual assets for ads. This translates marketing concepts into highly descriptive, effective image generation prompts.

## Workflow

### 1. Identify the Concept
- Determine the product, the target audience, and the core emotion/benefit to convey.

### 2. Structure the Prompts
Create prompts using the following strict structure:
- **Subject:** What is the main focus? (e.g., A sleek black coffee mug on a wooden desk).
- **Environment/Lighting:** Where is it? (e.g., Sunlit modern office, dramatic studio lighting).
- **Style/Format:** What is the aesthetic? (e.g., hyper-realistic product photography, 8k, cinematic, shot on 35mm lens).
- **Text/Layout Space:** (e.g., Negative space on the left side for ad copy).

### 3. Generate Outputs
- Provide 3-5 distinct image generation prompts.
- If you have an image generation tool available (like `generate_image`), offer to run the prompts for the user immediately.

### 4. Review
- Suggest overlay text (headlines) that would pair perfectly with each generated image.
