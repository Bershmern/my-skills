# AI UGC Hooks Generator

## Overview
Use this skill to generate scroll-stopping video ad hooks. UGC hooks must be visceral, fast-paced, and highly relatable to the target audience defined in `customer-avatars.md`.

## Workflow

### 1. Analyze the Avatar
- Read `customer-avatars.md` to identify the core pain points and desires.

### 2. Select Hook Frameworks
Apply the following proven hook frameworks:
1.  **The "Negative" Hook:** "Stop doing [common mistake] if you want [desired result]."
2.  **The "Story" Hook:** "How I fixed my [pain point] in just 3 days."
3.  **The "Direct Benefit" Hook:** "3 reasons you need this [product type] immediately."
4.  **The "Us vs. Them" Hook:** "Why everyone is switching from [competitor/old way] to this."
5.  **The "Visual" Hook:** (Scripting a bizarre or highly satisfying visual action for the first 3 seconds).

### 3. Generate 5-10 Variants
- Output 5 to 10 distinct, fully scripted 3-second hooks.
- Include both the **spoken script** and the **on-screen visual action/text**.

### 4. Next Step
- Ask the user which hook they want to expand into a full 30-second ad script.
