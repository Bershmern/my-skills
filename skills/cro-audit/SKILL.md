# CRO Audit Protocol

## Overview
Use this skill when the user asks you to audit a landing page, website, or mock up for conversion rate optimization. It relies on the `cro-brain.md` context (if available) and standard CRO best practices.

## Dependencies
- Requires a target URL, HTML content, or screenshot to audit.

## Workflow

### 1. Above the Fold Analysis
- Analyze the headline, subheadline, and primary Call to Action (CTA).
- Check the clarity of the Value Proposition (Does it pass the 5-second test?).
- Ensure hero imagery is relevant and high-quality.

### 2. Friction and Trust
- Look for social proof (reviews, testimonials, logos).
- Identify friction points (long forms, confusing navigation, lack of clarity).
- Check for risk-reversal (guarantees, easy returns).

### 3. Readability and Layout
- Check for easily scannable text (bullet points, short paragraphs).
- Ensure mobile responsiveness and tap targets.
- Verify visual hierarchy guides the eye to the CTA.

### 4. Output the Report
- Provide a prioritized list of recommendations (High, Medium, Low Impact).
- Suggest 3 distinct A/B tests to run based on the findings.
