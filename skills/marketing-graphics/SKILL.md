# Marketing Graphics (@noble_casca)

Use this skill when tasked with creating marketing graphics, image prompts, or design specs for the @noble_casca Instagram account.

## Guidelines
1. **Design Tokens**: Pull design tokens (colors, fonts, spacing) exclusively from `project-docs/brand-source-of-truth.md`. Never invent new colors/fonts/spacing.
2. **Content Split (Profit Brand)**:
   - **Growth**: Shareable, provocative content.
   - **Nurture**: Tutorial/credibility (matches existing @noble_casca pattern).
   - **Conversion**: Explicit offer/CTA (currently the gap).
3. **Grounding in Reality**: Ground every graphic idea in something real. Pull actual results from the Testimony and WorkHub databases via Notion (when access is available). Do not invent client outcomes.
4. **Execution**: If you lack access to accurate typographical rendering tools (e.g., standard `generate_image` often hallucinates text), provide exact specs/templates (or HTML/CSS/SVG templates) for the user or a design tool to execute, rather than generating a flawed image. Be honest about this limitation.
